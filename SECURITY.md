# Security policy

## Reporting a vulnerability

Please report vulnerabilities privately through [GitHub's private vulnerability reporting](https://github.com/9alvaro0/gitForge/security/advisories/new), not in a public issue.

Include what you found, how to reproduce it and the gitForge version. You'll get an answer as soon as possible, and credit in the release notes if you'd like it.

## Supported versions

Only the latest release receives fixes. gitForge updates itself through Sparkle, so most users are on it already.
