What's new in 1.7.0

  • Settings fill the window. Settings opens in the window itself with six panes (General, Appearance, Identities, Accounts, Git and Pull requests), Back returns you to the repository and section you left, and ⌘, reopens the last pane.
  • Tick several files at once. In Changes, ⌘-click and Shift-click tick files like in Finder, Shift-↑↓, Space and ⌘A do it from the keyboard, and right-clicking a ticked file stages, stashes or discards them all.
  • Switch branches with changes. When your changes block a checkout, gitForge offers to stash or discard just those files and then switches, instead of stopping with an error.

Fixes

  • gitForge reads each account's token from the Keychain once per launch, so it no longer asks for your keychain password on every fetch and refresh.
  • The Discard all button in the Changes toolbar no longer ends in an ellipsis that made it look cut off.

Improvements

  • Every link to Settings names the pane it opens, such as Open Accounts, and the user card now offers Manage Accounts next to Edit Identities.
  • Searching in ⌘K finds each Settings pane and the actions Connect account, New Profile and Follow Repository.
  • A folded sidebar stays folded the next time you open gitForge.
