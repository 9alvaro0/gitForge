What's new in 1.9.0

  • Undo what you just did. Reset, discard, delete a branch, drop a stash, move a branch or force-push, and the message that confirms it offers Undo, also with ⌘Z, until your next operation. If something changed in between, gitForge tells you instead of undoing on top of it.
  • Search the whole history. In History, Search history finds commits by message, author, content or path across the whole repository, not only the ones already loaded, and Return shows the one you pick in the graph.
  • History of any file. Right-click a file anywhere and choose Show file history to see every commit that changed it, renames included, with just that file's diff.
  • See who changed each line. Blame shows the commit, author and date next to every line, opens from any file or diff line, and Blame before this commit goes back one step at a time.
  • Get lost commits back. Repository > Recover Lost Commits… lists what your branches pointed to before each reset, amend or rebase, in plain words, and creates a branch on the one you need.
  • Faces next to commits. History, the commit detail and Branches show each author's avatar from your connected GitHub or GitLab account, or their initials, and clicking an author offers Only commits by….

Fixes

  • Commits no longer fail when a pre-commit hook takes more than a minute, and a failing hook now shows its full output with Retry and Commit without hooks instead of a short message.

Improvements

  • Help > Export Logs… saves a file with the errors gitForge showed, without tokens or passwords, to attach to a bug report.
