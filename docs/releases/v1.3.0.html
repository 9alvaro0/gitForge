What's new in 1.3.0

  • gitForge now speaks Spanish and European Portuguese. It follows your macOS language, or pick one in Settings › Language.
  • Updates install themselves: gitForge downloads new versions in the background and installs them when you quit, or right away with “Restart to Update”. Turn it off in Settings › Updates.
  • Commit, fetch, pull and push confirm with a toast that says what happened, like “Pushed 3 commits to origin/main” or “Fetched — 2 commits to pull from origin/main”.
  • Branch chips in History take the colour of their line in the graph, so it’s easier to see which branch is which.

Fixes

  • If an update fails to install, gitForge retries once and then offers a direct download instead of staying on the old version silently.

Improvements

  • Scrolling and selecting in long histories is smoother: rows no longer rebuild on every refresh.
