What's new in 1.1.0

A redesigned gitForge: a new interface from top to bottom, hosting accounts, and a long list of new tools for everyday git work. From this version on, gitForge updates itself.

A new interface

  • Native split-view window with Liquid Glass toolbars, a new sidebar with a repository switcher and a branch tree, and new themes, accents and densities.
  • Redesigned History, Changes, Branches & Tags, Stashes, Pull Requests, conflict resolver, Settings, Welcome and onboarding.
  • Command palette (⌘K) with fuzzy search and scopes for actions, repositories, branches, commits and files. ⇥ switches scope, ⌘↵ runs without closing.

History

  • New graph with lane colours and node shapes, and an inspector with the commit detail over the file diff.
  • Focus mode dims everything that isn't history of the selected commit.
  • The commit detail shows its signature and its CI status on GitHub and GitLab.
  • Drag a branch onto another branch or commit to merge, rebase or move it, with a preview of the resulting graph.

Changes

  • Stage, unstage and discard by hunk or by line.
  • Per-file +N −M counters, a file filter, stash of the selected files and ⌘↵ to commit.
  • Commit composer with amend and sign-off.
  • Diff options: wrap lines, hide whitespace and "Show N hidden lines" between hunks. Syntax highlighting in diffs.

Branches, stashes and conflicts

  • Branches table with a merged badge, comparison with main, and push of any branch from the inspector.
  • Stash detail with its files, including untracked ones.
  • Conflict resolver with "both" picks, manual editing of the result and Next conflict (⌥⌘↓).

Accounts and pull requests

  • Connect GitHub and GitLab accounts (including self-hosted instances) with device sign-in or a token. Each repository uses the account of its remote for fetch, pull, push, clone and pull requests.
  • Pull requests show checks, approvals and closed requests.
  • Clone lists your account's repositories, checks the URL before cloning, and supports shallow and submodule clones. New Repository… (⌥⌘N) creates and opens a repository.
  • Per-repository git identities with named profiles.

Reliability

  • Changes made outside the app (checkout, commits on nested branches, fetch) now show up right away.
  • Stashes are addressed by commit, so Drop can no longer remove a different stash.
  • Your git configuration (colours, external diff tools) no longer breaks diffs.
  • Large repositories and large diffs render faster.
  • Security hardening: tokens never appear in logs or errors, and only web links open from pull requests and CI.
  • VoiceOver labels and actions, and support for Increase Contrast and Reduce Motion.

Updates

  • gitForge now checks for updates on its own. You can also use Help → Check for Updates….
